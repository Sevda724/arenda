# Аренда жилья · Алматы

Аналитический дашборд по долгосрочной аренде жилой недвижимости в Алматы: квартиры, комнаты, дома/дачи. Источник данных — выгрузка объявлений krisha.kz (срез на август 2026).

**Открыть дашборд:** [`almaty_rent_dashboard.html`](almaty_rent_dashboard.html) — самодостаточный HTML-файл, работает офлайн (карта и данные встроены), открывается двойным кликом в браузере.

## Что внутри

- Карта объявлений (векторная, с встроенной подложкой OpenStreetMap) с фильтрами и границами районов
- Медианная/средняя цена по районам, типу жилья, комнатности и этажу
- Матрица цены за м² (район × комнатность)
- Список объявлений с сортировкой и постраничной навигацией
- Фильтры: тип жилья, район, комнатность, цена, площадь, собственник, санузел, мебель, животные/дети, этаж

## Данные

- `address_city_districts.xlsx` — справочник районов Алматы (геометрия полигонов)
- `Крыша/` — сырая выгрузка объявлений krisha.kz (объявления, параметры объявлений, категории)

## Пересборка дашборда из данных

Пайплайн в `scripts/`, запускать по порядку:

```
python 1_prep.py          # фильтрует жилую аренду, определяет район, парсит комнаты/площадь/этаж
python 2_export.py        # собирает компактный data.json (записи + границы районов)
python 2b_fetch_basemap.py  # разово, нужен интернет — тянет и вшивает подложку карты
python 3_splice.py        # вставляет data.json в шаблон, пишет итоговый almaty_rent_dashboard.html
```

Промежуточные файлы (`scripts/build/`) не хранятся в репозитории — пересоздаются пайплайном.
